AMTEC 명함매니저 1.0

구성: index.html, manifest.webmanifest, sw.js

사용:
1. 폴더 내 세 파일을 HTTPS 정적 웹호스팅(Netlify, GitHub Pages 등)에 업로드합니다.
2. 아이폰 Safari로 배포된 HTTPS 주소를 엽니다.
3. 공유 -> 홈 화면에 추가.
4. 촬영 -> 문자 자동 인식 -> 결과 확인 -> 저장.
5. 명함 목록에서 주소록 저장을 눌러 .vcf 파일을 연 뒤 연락처에 추가합니다.

주의:
- OCR은 Tesseract.js CDN 및 언어 데이터 다운로드가 필요합니다. 최초 인식에 시간이 걸릴 수 있습니다.
- 문자 인식 결과는 완벽하지 않으며 반드시 수동 확인해야 합니다.
- 명함 사진/정보는 localStorage에 저장되며 용량 제한이 있습니다. 정기적으로 JSON 백업하세요.
- 별도 서버/클라우드 동기화, 중복 연락처 자동 병합, 주소록 직접 쓰기는 지원하지 않습니다.
- 사진과 연락처 정보는 브라우저에 보관되지만 OCR 라이브러리/언어 데이터 다운로드를 위해 외부 CDN에 접속합니다.
