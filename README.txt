AMTEC 명함매니저 2.0

GitHub 저장소 루트에 index.html, sw.js, manifest.webmanifest 3개 파일을 덮어쓰기 업로드하세요. README.txt는 선택 사항입니다.
기존 브라우저 저장 명함은 동일한 localStorage 키를 유지해 보존합니다. 그래도 업데이트 전에 앱의 백업/안내에서 JSON 백업을 받으세요.
변경: 한글 띄어쓴 이름, 직책/부서 분리, 복수 전화/팩스/이메일, 여러 주소, VCF 확장, 서비스워커 캐시 갱신.
주의: OCR은 브라우저 내 Tesseract.js로 처리하므로 이름/회사명 인식이 완벽하지 않습니다. 원본과 대조 후 저장하세요. GitHub Pages는 공개 웹사이트이므로 개인정보가 포함된 JSON 백업 파일이나 명함 사진을 저장소에 올리지 마세요.
