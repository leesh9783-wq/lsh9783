저장된 명함

데이터 백업

명함 정보는 현재 사용 중인 브라우저에 저장됩니다. Safari 기록/웹사이트 데이터를 삭제하거나 다른 기기를 사용하면 정보가 보이지 않을 수 있습니다. 주기적으로 백업해 주세요.

복원 시 기존 명함은 유지되고 동일 ID만 갱신됩니다. 명함 사진도 백업에 포함됩니다.

아이폰 사용 방법

1. Safari로 웹앱 주소를 엽니다.
2. 공유 버튼 → '홈 화면에 추가'를 선택합니다.
3. 명함을 촬영하고 '문자 자동 인식'을 누릅니다.
4. 인식 결과를 확인한 뒤 저장합니다.
5. '주소록 파일 만들기'로 .vcf 파일을 내려받아 열고 연락처 추가를 선택합니다.

이 HTML 파일만 열어도 수동 입력과 저장은 사용할 수 있지만, 자동 인식 모듈과 홈 화면 설치를 안정적으로 사용하려면 HTTPS 웹 호스팅이 권장됩니다. iOS에서 VCF 열기 방식은 버전과 브라우저에 따라 다를 수 있습니다.
